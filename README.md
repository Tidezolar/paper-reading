# Paper reading dashboard

Static HTML reading notes published through GitHub Pages.

The `site/` directory contains generated pages, extracted figures, and fonts. Source PDFs, local configuration, and editing JSON are excluded.

To update from the server, run `python3 scripts/prepare_github_pages.py` in the paper-reading directory, then commit and push this repository.

Browser edits remain local unless explicitly exported; GitHub Pages does not write edits back to this repository.
